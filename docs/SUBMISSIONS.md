## Backlog → 100

A daily cron researches new venues and appends them here. Rules for anything it adds:

1. **Git-PR venues first** — no forms, no accounts, no fees.
2. **Verify before listing**: repo not archived, pushed within ~6 months, and actually
   merging outside PRs. A dead awesome-list is not a venue.
3. **Free only.** Paid placements need a human decision — flag, don't add.
4. **No duplicates** — check the tables above first.
5. Record `★`, last-pushed date, and the evidence that it accepts submissions.

> **2026-08-06 run coverage:** searched awesome-* lists across nextjs / shadcn-ui / saas-boilerplate / supabase / drizzle / stripe / turborepo / monorepo / tailwind / open-source-saas. **Every active, fitting, free awesome-list with meaningful reach already has an open or merged MailKite PR** (see Tier 1 + log). New venues found this run were all **stale (pushed >6mo, not merging)** or **sub-10★** — recorded as `[-]` in Tier 1 to prevent re-research. No new viable venue to add; **0 new PRs / 0 emails** this run (quality over volume; all live targets already covered).
